# 💱 CambioAlDía

Aplicación web tipo fintech para consultar tasas de referencia (**BCV**, **Paralelo**, **Euro BCV** y **USDT P2P**), calcular brechas cambiarias y realizar conversiones bidireccionales con mensajes formateados listos para compartir por WhatsApp.

## ✨ Características
- **Conversión bidireccional en tiempo real:** Calcula de Divisas → Bolívares o de Bolívares → Divisas al instante.
- **Brecha cambiaria automática:** Muestra la diferencia en bolívares y porcentaje entre el dólar Paralelo y el BCV.
- **Edición y guardado local:** Modifica las tasas desde el botón **Tasas** y los valores quedan guardados automáticamente en el navegador (`localStorage`).
- **Listo para WhatsApp:** Genera un resumen limpio del cálculo con un toque para enviarlo directo a clientes o contactos.

## 🚀 Despliegue
Proyecto 100% estático (HTML5, CSS3 y JavaScript Vanilla), listo para desplegar sin dependencias en **GitHub Pages** o **Vercel**.
